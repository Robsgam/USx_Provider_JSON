Routing and Configuration Information:
Save Bytes (Primary routing) Mnemonic (Secondary routing)
 The TLETS assigned ORI for a device (or for the site) should be placed in the <Authentication>/<ORI> field in the ConnectCIC header.
 The TLETS assigned TDAC or Mnemonic for a device should be placed in the <Authentication>/<Mnemonic> field in the ConnectCIC header.
 The TLETS assigned User ID should be placed in the <Authentication>/<UserName> field in the ConnectCIC header.
If the site wants to use regional lookups, the vendor can send <RegionId>{RegionIdentifier}</RegionId> with each transaction that allows regional inquiries. If the site wants ALL transactions that allow regional inquiries sent to the region system without having to send the RegionIdentifier on each transaction, the following configuration setting will allow such. Note: regional transactions will not work until authorized by the state and or regional being used.
Using the ConnectCIC TWE Config Tool, choose "RegionID" from the "Other State Settings" dropdown and set the value to the RegionIdentifier. For example the regional identifier in the Dallas region is DTJ. This change will have no effect until ConnectCIC is restarted.

Security Requirements: Agency must complete a TLETS Security Plan, submit to the state, and get approval. Information regarding requirements is available to agencies on the TCIC Website.
Prime Vendors must submit a Security Plan to agency along with fingerprints for background checks of any individual who could be exposed to CJIS data. This is necessary for an agency to gain approval to implement the interface.
