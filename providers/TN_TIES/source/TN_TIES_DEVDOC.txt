Tennessee (TN) TIES
Transport: TCP/IP
Routing and Configuration Information: Route by ORI ­ Save Information is by token
 The TIES assigned ORI for a device (or for the site) should be placed in the <Authentication>/<ORI> field in the ConnectCIC header.
Security Requirements:
Background Checks ­ Tennessee requires each vendor to have any personnel who will be working with secure data (transactions) to be fingerprinted for background checks and they require a NCIC card and Tennessee card charging $24 for each card ($48/person). You will also need to complete the security paperwork (CJIS Security Addendum and TBI Vendor Eligibility Form) before your first Tennessee agency is installed. These can be done directly with TBI. Information can be obtained through an agency or through the Tennessee Bureau of Investigation (615-744-4001).
Logon Requirements: None
Certification Requirements: None TBI does encourage Vendors to test against their TIES Test Server. CommSys has tested.
Data-Mined Transactions: NCIC (QA, QB, QG, QV, QW) and DMV (Person and Vehicle) Tags returned from Data mining
