## Version tracking for a HAND-BUILT provider

There is no build script, so the version cannot be read from `$Version = "X.Y"`. It is carried in
**five** places and every one advances together on a bump:

| Carrier | Value at v1.0 |
|---|---|
| Root JSON filename | `CA_eSUN_v1.0.json` |
| Provider bundle `description` | `Provider configuration for CA_eSUN v1.0 -- HAND BUILT BY ENGINEERING ...` |
| `logs/.test_version` | `1.0` |
| `docs/tracking/` STATUS / SQVR / BUILD_NOTES / CHANGELOG / REBUILD_TRACKER | v1.0 |
| Every test log filename + header | `CA_eSUN_v1.0_<combo>.txt`, `JSON Version: 1.0` |

`Get-BuildVersionForProvider` (tools/_test_provenance.ps1) falls back to the filename, then the
bundle description, precisely so this provider stays trackable. Before that fallback existed, every
log was stamped `CA_eSUN_vunknown_*` and counted for nothing while the importer reported success.
