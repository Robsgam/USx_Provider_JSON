 The Chula Vista assigned ORI for a device (or for the site) should be placed in the <Authentication>/<ORI> field in the ConnectCIC header. o An Agency ORI may be provided in the <OriginatingAgencyORI> or <Authentication/OriginatingAgencyORI> when running a transaction on behalf of another agency or to provide the Agency ORI for an entry/edit transaction. ConnectCIC may replace the <Authentication/ORI> value transmitted to the interface with the provided OriginatingAgencyORI in this case. o An entry/edit transaction is any ConnectCIC transaction that ends with one of these suffixes: Entry, Modify, Clear, Locate, or Cancel
 The Chula Vista assigned Mnemonic for a device should be placed in the <Authentication>/<Mnemonic> field in the ConnectCIC header.
 The Chula Vista assigned User ID should be placed in the <Authentication>/<UserName> field in the ConnectCIC header.
 The agency assigned Terminal Identifier should be placed in the <Authentication>/<DeviceId> field in the ConnectCIC header.
 A valid CLETS Purpose Code value must be supplied in the <CaRequestPurposeCode> element of the ConnectCIC transaction body as a sibling to all other transaction-specific fields. For more information about the CaRequestPurposeCode element, see the Transaction Requirements section below.
Security Requirements:
None known.

Logon Requirements: None

Transaction Requirements:
Beginning July 21, 2021 CLETS requires a "Purpose Code" field to be supplied with every CLETS transaction. The information regarding this purpose code was published by CLETS in Information Bulletin 20-03-CJIS and covers the "Purpose Code" field added to satisfy Assembly Bill (AB) 1747.

Any transaction which does not supply a valid Purpose Code value will be rejected by CLETS. ConnectCIC does not default the value of field; it must be provided by the partner implementation as a user selectable field.

The CLETS "Purpose Code" value must be supplied to ConnectCIC via the <CaRequestPurposeCode> element as a sibling to the transaction-specific elements covered in this document. The <CaRequestPurposeCode> element is mandatory for all transactions.

The element is a single character value which may be one of the following:

 C ­ Criminal Justice  I ­ Immigration Enforcement  U ­ Investigate Violations of Title 8, section 1325 of the United States Code
