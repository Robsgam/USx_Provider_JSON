# CONTEXT (v3.0 galvanization, 2026-07-23): several metadata queries expose two combination
# VARIANTS under one keyRef (a Name/OLN pair, or a Hull/Reg pair). The two variants have
# DIFFERENT primaryFieldReference but overlapping/identical set[] shapes -- they are
# form-identical shadows: the client form cannot distinguish which variant the officer intends
# from field content alone, and the server routes by keyRef, not by which variant matched. Per
# the CA_CLETS IV.4* / CA_eSUN Boat precedent, only ONE variant per keyRef is built; the other
# is dropped. audit_metadata reports the dropped variant's set field as "missing from JSON set[]"
# (WARN, informational -- does not gate enforce, which counts metadata FAILs only). These are the
# accepted, intentional drops:
#
#   BoatQuery      QB  -> built Hull variant  (set BoatHullIdNumber); dropped Reg variant
#   BoatQuery      BQ  -> built Reg variant   (set RegistrationNumber); dropped Hull variant
#   DriverLicense  QWDN-> built Name variant  (Name+DOB+Sex+Race);     dropped OLN variant (shadow of DQ-OLN)
#   DriverLicense  DQ  -> built OLN variant   (set OperatorLicenseNumber); dropped Name variant (shadow of QWA)
#
# Hull>Reg (Boat) and OLN>Name (DL) identifier-priority guardrails make the built variants
# mutually exclusive by co-entry; QWDN vs QWA is isolated by raceCode EXISTS/NOT_EXISTS.

# KEYREFS NARROWED 2026-08-07 -- these six rows are UNCHANGED IN MEANING; only the KeyRef column
# was made branch-identifying. Each row retires ONE metadata VARIANT, but it named the bare keyRef
# (QB / BQ / QWDN / DQ) -- and every one of those is also a BUILT combo here, so
# Test-RegisteredUnbuilt's exact-match arm suppressed the ENTIRE keyRef family, silently skipping
# the built sibling's fidelity comparison too. A KEYREF IS NOT A VARIANT.
# The corrected form uses the tool's narrowed prefix bridge: <metadataKeyRef><PrimaryField>, whose
# suffix must name a set[] field of the alternative being retired -- so QBRegistrationNumber
# suppresses only QB{RegistrationNumber} and leaves the built QB{BoatHullIdNumber} compared.
