LA-SPECIFIC DESIGN DECISIONS (v2.0):
  - State in set[] for Vehicle combos (metadata says SET, not any[])
  - ImageIndicator no default on Person (DP/DQ routing toggle)
  - RaceCode in QWDN set[] (LA-specific, most states have Race in any[])
  - PurposeCode in DH set[] with default='C' (metadata says SET)
  - GunTypeCode added to Firearm (was missing in v1.0 per SQVR open issue)
  - ArticleTypeCode in any[] (metadata says ANY, not set[] like most states)
  - Boat RegistrationNumber maxLength=8 (LA-specific)
  - DP combo: ImageIndicator in set[] means officer must actively select Y/N
    for photo query. No default = DQ fires by default when only OLN entered.
  - DQ Name UNREACHABLE: XML has 5th combo DQ(Name) with identical set[] to QWA,
    later in order -> never fires per LIMITATION #3. Dropped to 4 combos.
