                           Illinois FoxTalk/OFML Requirements

                           Improper XML Placeholders and Text Submissions

Recently, agencies using an interface (Computer Aided Dispatch (CAD), Record Management
System (RMS), Mobile Data Computer (MDC)) to query LEADS information and/or perform file
maintenance (enter, modify, cancel, clear) on Illinois' hot files were required to migrate to the
new connection specifications, FoxTalk/OFML. During recent administrative reviews, many
interfaces were submitting non-conformant messages.

Improper XML Placeholders

         As part of the FoxTalk/OFML specifications, certain fields must be submitted for
         transactions to be accepted. These fields are contained in the OFML header section and
         defined by the Illinois Specific Requirements found here -
         https://isp.illinois.gov/LawEnforcement/LEADSInterfaces

LEADS Administration has become aware of interfaces submitting placeholder or self-
closing tags for the USR (<USR/>) and ORI (<ORI/>) fields ­ meaning the element has no
content. To date, these messages have passed current edits. However, adjustments have
been made to the edits to interrogate each of the above required HDR fields and reject
those messages with improper configurations. See examples of correct and incorrect
messages here https://isp.illinois.gov/LawEnforcement/LEADSInterfaces.

Text Submissions

Additionally, some interfaces are submitting messages using legacy message keys via

embedded TXT elements. These messages must also be changed to reflect FoxTalk/OFML

standards.        See examples of correct and incorrect messages here

https://isp.illinois.gov/LawEnforcement/LEADSInterfaces.

On November 1, 2026, the edits will be implemented to reject improperly formatted messages.
As of this date, messages formatted with self-closing tags or legacy message keys will be
rejected. Agencies using an interface (Computer Aided Dispatch (CAD), Record Management
System (RMS), Mobile Data Computer (MDC)) must contact their vendor to confirm if changes are
required.
