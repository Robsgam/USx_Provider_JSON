Routing and Configuration Information:
Mnemonic Routing
 The state assigned UserId for each user should be placed in the <Authentication>/<UserName> field in the ConnectCIC header.
 The LEADS assigned ORI for a device or agency should be placed in the <Authentication>/<ORI> field in the ConnectCIC header.
 The LEADS assigned CDC name (maximum 10 characters) for the agency submitting the transaction should be placed in the <Authentication>/<CDCName> field. If only one agency is operating through the same message switch connection the CDC name can be set in the CDCName field found in the "Other State Settings" drop down list.
 The state assigned ConnectionName should also be set in the "Other State Settings" drop down list.
 The application device identifier used for routing responses should be placed in the <Authentication>/<Mnemonic> field in each transaction.

Excerpt From LEADS Administrative Rules - Section 1240.40 Connecting to LEADS a) To connect to LEADS, an agency must have computer hardware and computer software, and be connected to a communications link to the LEADS Data Center in Springfield. For each of these requirements, there are various options. In addition, the agency must meet certain planning and administrative responsibilities.
 Notify LEADS Administrator When an agency desires to participate in LEADS and meets the qualifications described in Section 1240.30 or when an agency wishes to change its method of connecting to LEADS, it must make a written request at least 90 days in advance of the desired connection date. The request must be sent to the LEADS Administrator and must state: 1) When connection to LEADS is desired; and 2) What equipment and connecting options are planned by the agency.
