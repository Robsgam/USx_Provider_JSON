QUERY PATHS -- 21 combos, ALL CONFIRMED (56 logs, 56 PASS, 0 FAIL)
==================================================================
  "Fills" is what the officer types to reach the path. "Optional" rides in any[] and is transmitted
  only when filled. "Routes when" is the existence gate that picks between sibling paths -- these are
  existence-only by design (a value-comparison condition poisons the whole array).
  Suffixes in the log filenames: _any = every optional filled, _af_<field> = one optional toggled
  (its value always DIFFERS from the form default, else the test proves nothing),
  _guardrail_vs_<other> = both identifiers filled, to prove which one wins.
