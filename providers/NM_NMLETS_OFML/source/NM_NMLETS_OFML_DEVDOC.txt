Routing and Configuration Information: Mnemonic Routing
 The NMLETS assigned ORI for a device (or for the site) should be placed in the <Authentication>/<ORI> field in the ConnectCIC header.
 The NMLETS assigned mnemonic or terminal id for a device should be placed in the <Authentication>/<Mnemonic> field in the ConnectCIC header.
 The NMLETS assigned user id for a person should be placed in the <Authentication>/<UserName> field in the ConnectCIC header.

Security Requirements: None known at this time.

Logon Requirements: No login is required by NMLETS.

Certification Requirements: Agency sponsor is required.
Data-Mined Transactions: NCIC (QA, QB, QG, QV, QW) and DMV (Person and Vehicle) Tags returned from Data mining
