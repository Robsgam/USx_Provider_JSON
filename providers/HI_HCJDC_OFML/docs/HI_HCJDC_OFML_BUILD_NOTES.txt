XML <Any> INSIDE <Set> PATTERN:
  Every <Any> element in this XML is inside <Set>, meaning optional companions.
  Translated to empty any=@() in all combos. Platform sends ALL attributes with values
  regardless of combo requirements. Empty any[] is correct and more robust.

PDF vs XML DISCREPANCIES (metadata wins):
  BoatQuery:  XML uses <Choice> elements, PDF shows 2 simple combos -- functionally equivalent
  DL:         XML has QW combo (Wanted Person), PDF Basic Queries does NOT show it
  VehicleReg: XML has QV combos (Stolen Vehicle), PDF has them in Expanded section
  State2-5:   PDF says "submit up to 5 states" -- not implementable, excluded
