1. VehicleRegistrationQuery -- Vehicle Entity
================================================================================

  QIDM: VehicleRegistrationQueryQIDM
  QIF:  Vehicle
  Combos: M55L (in-state plate), M55S (in-state VIN), RQ (OOS plate),
          QVV (stolen VIN), QVP (stolen plate), RQV (VIN fallback)
  Optional fields: VehicleMakeCode, VehicleModelCode, VehicleYear,
                   ImageIndicator, VehicleTypeCode (default=1)

  M55L -- Plate + State(HI) + VehicleTypeCode [CONFIRMED]
    set: LicensePlateNumber, RegistrationState, VehicleTypeCode
    any: (empty)
    keyReference: M55L
    Fires when: State=HI (in-state) and Plate present
    Defaults: State=HI, VehicleTypeCode=1 (Auto), ImageIndicator=N

  M55S -- VIN + State(HI) + VehicleTypeCode [CONFIRMED]
    set: VehicleIdentificationNumber, RegistrationState, VehicleTypeCode
    any: (empty)
    keyReference: M55S
    Fires when: State=HI (in-state) and VIN present, no Plate

  RQ -- Plate + State(non-HI) [CONFIRMED]
    set: LicensePlateNumber, RegistrationState
    any: (empty)
    keyReference: RQ
    Fires when: State != HI (out-of-state) and Plate present

  QVV -- VIN + VehicleMakeCode [PENDING]
    set: VehicleIdentificationNumber, VehicleMakeCode
    any: (empty)
    keyReference: QVV
    Stolen vehicle by VIN

  QVP -- Plate + State [PENDING]
    set: LicensePlateNumber, RegistrationState
    any: (empty)
    keyReference: QVP
    Stolen vehicle by Plate (co-fires with M55L/RQ on shared fields)

  RQV -- VIN [PENDING]
    set: VehicleIdentificationNumber
    any: (empty)
    keyReference: RQV
    VIN fallback (lowest priority)

  Priority order: M55L > M55S > RQ > QVV > QVP > RQV [PENDING]
    M55 in-state first, then OOS plate, then stolen, then VIN fallback

  APPROVED SKIP -- QV (by LicensePlateNumber) and QV (by VehicleIdentificationNumber):
    Metadata lists these 2 generic QV combos; intentionally NOT built. QV is a
    catch-all transaction, not an authorized basic query; plate and VIN paths are

    Not a coverage gap -- excluded from the test matrix.

  Optional fields: SexCode, RelatedSearchHitIndicator (default=Y)

  DQN -- OLN + State [CONFIRMED]
    set: OperatorLicenseNumber, RegistrationState
    any: (empty)
    keyReference: DQN
    Defaults: State=HI

  DQ -- Name + SexCode + DOB [CONFIRMED]
    set: Name, SexCode, BirthDate
    any: (empty)
    keyReference: DQ
    Name uses FormatStringRuleHandler: arguments=[' ',' ',' ']
    BirthDate uses CommsysParseDateRuleHandler: yyyy-MM-dd -> MMddyyyy

  QW -- Wanted Person: Name + DOB (no SexCode) [CONFIRMED]
    set: Name, BirthDate
    any: (empty)
    keyReference: QW
    Fires when: Name+DOB present but SexCode absent
    NOTE: In XML metadata inside DriverLicenseQuery but NOT in PDF Basic Queries.
    Included per source authority rule (metadata wins).

  Priority order: DQN > DQ > QW -- CONFIRMED (note; backed by combo logs T6/T7/T8)
    OLN first; Name+Sex+DOB second; Name+DOB without Sex falls to QW

  Sex optional behavior -- CONFIRMED (note; backed by combo logs)
    SexCode present -> DQ fires (Name+Sex+DOB); absent -> QW fires (Name+DOB).
    NIBRS reverse-lookup confirmed (Male->M). Live v2.9 T7 (DQ) / T8 (QW).

  OOS routing -- State != HI -- CONFIRMED (note)
    State rides along via any[] (NCIC reverse-lookup California->CA). Live v2.9 T21 (DQN + State=CA).

  RMS co-fire -- CONFIRMED (note)
    RMS Person fired alongside CommSys (dlNumber / firstName+lastName+dateOfBirth+sexAttrId). Live v2.9 T6/T7/T8.
