1. VehicleRegistrationQuery -- Vehicle Entity
================================================================================

  QIDM: VehicleRegistrationQueryQIDM
  QIF:  Vehicle (3 cards: SEARCH OPTIONS / PLATE SEARCH / VIN SEARCH)
  Combos (v3.0+ OOS-first order): RQ (OOS plate), RQV (OOS VIN),
          M55L (in-state plate), M55S (in-state VIN), QVV/QVP (stolen, dormant)
  Optional fields: VehicleMakeCode, VehicleYear, ImageIndicator,
                   VehicleTypeCode (default=1, Auto)
  Routing principle (v3.0+): out-of-state is reached by ADDING fields, never by
    clearing Vehicle Type. Plate discriminator = Plate Type/Year presence; VIN
    discriminator = State presence. First-match firing on combos ordered OOS-first.
  Plate-wins guardrail (v3.6): LicensePlateNumber NOT_EXISTS condition on RQV/QVV/M55S
    ensures that when Plate is present, all VIN combos exit the union pool. Plate wins.
  vehicleYear (v3.6): added to RQV/M55S/QVV any[]; serializes on VIN searches only.

  RQ -- OOS plate (Plate + PlateType + PlateYear) [PENDING]
    set: LicensePlateNumber, LicensePlateTypeCode, LicensePlateYear
    any: ImageIndicator, RegistrationState
    keyReference: RQ
    Fires when: Plate Type AND Plate Year filled (the OOS-plate signal). State
      rides along via any[]. VehicleTypeCode does NOT bleed (M55L's
      LicensePlateTypeCode NOT_EXISTS condition exits it from the union pool).
    Live v3.6 T4: Plate=ABC123 + PlateType=PC + PlateYear=2020 + State=CA ->
      XML LicensePlateNumber/LicensePlateTypeCode/LicensePlateYear/State=CA/Image=N,
      VehicleTypeCode ABSENT. RMS registrationStateAttrIds+tag.
    Live v3.6 T6 (DECISIVE -- plate-wins): All fields simultaneously (+ VIN+Make) ->
      CommSys XML = plate only. VehicleIdentificationNumber+VehicleMakeCode ABSENT.

  RQV -- OOS VIN (VIN + State) [PENDING]
    set: VehicleIdentificationNumber, RegistrationState
    any: ImageIndicator, vehicleYear
    conditions: LicensePlateNumber NOT_EXISTS (plate-wins guardrail, v3.6)
    keyReference: RQV
    Fires when: VIN + State filled AND LicensePlateNumber absent. State is the VIN OOS
      discriminator. VehicleTypeCode does NOT bleed (M55S RegistrationState NOT_EXISTS
      exits it). vehicleYear serializes when filled (v3.6 any[] fix).
    Live v3.6 T5: VIN=233HNFHFG783634 + State=CA + Year=2019 ->
      XML VIN/State=CA/VehicleYear=2019/Image=N. VehicleTypeCode ABSENT. vehicleYear confirmed.
      RMS registrationStateAttrIds+vinNumber.

  M55L -- in-state plate (VehicleTypeCode + Plate) [PENDING]
    set: vehicleTypeCode, LicensePlateNumber
    any: ImageIndicator, RegistrationState
    conditions: LicensePlateTypeCode NOT_EXISTS (exits pool for OOS plate / RQ)
    keyReference: M55L
    Fires when: bare Plate present (Vehicle Type defaults to 1=Auto, auto-satisfying
      the server's in-state requirement). Defaults: VehicleTypeCode=1, ImageIndicator=N.
    Live v3.6 T2: Plate=ABC123 -> XML LicensePlateNumber/VehicleTypeCode=1/Image=N. RMS tag.
    Live v3.6 T7 (DECISIVE -- plate-wins): Plate+VIN (no State, no PlateType/Year) ->
      M55L fires; VehicleIdentificationNumber ABSENT. M55S exits on LicensePlateNumber NOT_EXISTS.

  M55S -- in-state VIN (VehicleTypeCode + VIN) [PENDING]
    set: vehicleTypeCode, VehicleIdentificationNumber
    any: ImageIndicator, vehicleYear
    conditions: RegistrationState NOT_EXISTS AND LicensePlateNumber NOT_EXISTS (v3.6)
    keyReference: M55S
    Fires when: bare VIN present, no State, no Plate. Both conditions must pass.
      Defaults: VehicleTypeCode=1, Image=N. vehicleYear serializes when filled (v3.6).
    NOTE: RegistrationState NOT in any[] (v3.4 fix -- semantic contradiction; M55S only
      fires when State absent). LicensePlateNumber NOT_EXISTS added v3.6 (plate-wins).
      Bare Plate+VIN (no State, no PlateType/Year): without this condition, M55L and M55S
      both satisfy and VIN bleeds into the plate union pool. With it: M55S exits. Clean.
    Live v3.6 T3: VIN=1HGNM8363783 + Year=2019 (no State, no Plate) ->
      XML VIN/VehicleTypeCode=1/VehicleYear=2019/Image=N. vehicleYear any[] fix confirmed.

  QVV -- stolen VIN (VIN + VehicleMakeCode) [DORMANT]
    set: VehicleIdentificationNumber, VehicleMakeCode
    any: ImageIndicator, RegistrationState, vehicleYear
    conditions: LicensePlateNumber NOT_EXISTS (plate-wins guardrail, v3.6)
    keyReference: QVV
    DORMANT by design: shadowed by M55S/RQV. Server auto-generates QV/stolen (QRDM).
    LicensePlateNumber NOT_EXISTS prevents VehicleMakeCode from bleeding into plate XML
    via union pool when Plate+VIN+Make are all filled simultaneously (v3.6 fix).

  QVP -- stolen plate (Plate + State) [DORMANT]
    set: LicensePlateNumber, RegistrationState
    any: ImageIndicator
    keyReference: QVP
    DORMANT by design: ordered last; shadowed by RQ/M55L for any plate entry.
      Server auto-generates QV/stolen (QRDM data-mined). Not live-fireable from form.

  M55L_guardrail -- plate-wins: Plate+VIN co-entry -> plate path wins (bare plate -> M55L per
    v4.7 CHECK 16 routing; +Type -> RQ), VIN absent from XML. Was mislabelled RQ_guardrail
    until the 2026-07-02 content-based relabel (sim expectation corrected). [PENDING]
    v4.9 live-proven 2026-07-17: M55L_guardrail_vs_M55S + M55L_guardrail_vs_RQV both PASS
    (captured combo names carry a _vs_<loser> suffix the SQVR line's generic label predates).

  Priority order: RQ > RQV > M55L > M55S > QVV > QVP -- CONFIRMED (live v3.6 T1-T7)
    OOS-first (add fields to reach OOS); in-state plate/VIN next; stolen dormant last.
    v3.6 live T6 (all-fields): RQ fires alone; RQV/QVV/M55S all exit on NOT_EXISTS. Clean.
    v3.6 live T7 (bare Plate+VIN): M55L fires; M55S exits on LicensePlateNumber NOT_EXISTS.

  APPROVED SKIP -- generic QV catch-all (by LicensePlateNumber / by VIN):
    The 2 generic QV combos in metadata are intentionally NOT built as standalone
    user combos; stolen lookup is server-generated (QVV/QVP dormant + QRDM).
    Confirmed not-to-build (user, 2026-06-22). Not a coverage gap.

  OOS routing -- reached by adding fields -- CONFIRMED (note; backed by live v3.6 T2-T5)

  RMS co-fire -- CONFIRMED (note; backed by live v3.6 T2-T7)
