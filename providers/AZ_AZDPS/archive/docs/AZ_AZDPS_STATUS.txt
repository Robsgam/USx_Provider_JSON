ARCHITECTURE (v1.1 -- Phase 1)
--------------------
Entities: Vehicle, Person, Firearm, Article, Boat
QIFs:     5 total (one per entity, single card each)
QIDMs:    8 CommSys QIDMs (all targetEntity + query pairs confirmed unique)

  VehicleRegistrationQuery   ACVR (Plate+Badge) + ACVRV (VIN+Badge -- invented keyRef)
  AzAzdpsDriverLicenseQuery  DQ (OLN) + DQN (Name -- inv) + DQSS (SSN -- inv) + ACWL (Badge+Name)
  DriverHistoryQuery         KQ (OLN+StateDH) + KQH (Name+StateDH -- inv) [DH-suffix isolation]
  GunQuery                   ACQG (Badge+Serial)
  ArticleSingleQuery         ACQA (Badge+Serial+TypeCode)
  BoatQuery                  ACQB (Reg+Badge) + ACQBH (Hull+Badge -- inv) + BQ (Reg) + BQH (Hull -- inv)
  WMPIWantedPersonInquiry    ACQW (Name+DOB+Sex+Race) + ACQWN (NCICNumber -- inv)
  WMPIMissingPersonInquiry   ACQM (Name+descriptors) + ACQMN (NCICNumber -- inv)

Badge:   dexStateUserId hidden InpH on all 5 QIF forms. Auto-populated via
         CommsysGetDexStateUserIdRuleHandler from officer RMS profile.
         QIDM BadgeNumber attribute sourceField='dexStateUserId' on all badge-required QIDMs.
         Badge field removed from all visible form layouts.

State:   NCIC confirmed. Single visible RegistrationState (attributeTypeId=STATE, initialValue=AZ).
         QIDM: sourceField=RegistrationState, codeTypeProvider=NCIC.
         DH: hidden StateDH (initialValue='AZ') -- State mandatory in KQ/KQH set[].

Sex:     NIBRS confirmed. attributeTypeId=SEX + codeTypeProvider=NIBRS.
         -> Form stores attribute ID; CommSys QIDM converts to M/F/U via NIBRS.
         -> RMS useAttributeId=True passes attribute ID directly (sex filtering works).

Race:    codeTypeCategory=NIBRS_RACE, codeTypeSource=NIBRS (avoids AP #3 numeric ID issue).

Date:    yyyyMMdd (AZ-specific -- NOT MMddyyyy like NJ).

DH:      DH-suffix fieldIds (OperatorLicenseNumberDH, NameLastDH, NameFirstDH,
         NameMiddleDH, NameSuffixDH, BirthDateDH, SexCodeDH, StateDH).
         KQ/KQH single QIDM with invented KQH keyRef (DALL+DALH pattern from NY).
