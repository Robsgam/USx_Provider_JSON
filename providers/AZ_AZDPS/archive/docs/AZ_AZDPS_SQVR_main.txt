AZ_AZDPS -- Supported Query Validation Report
==============================================
Last updated: 2026-04-20
Current version: 1.0 (Phase 1 -- single card per entity; all paths on Person form)
Provider: AZ_AZDPS
Format: [CONFIRMED] / [PENDING] / [FAIL]

Each entry documents what CommSys XML is expected for a given query path.
Update this file immediately after each test run.

================================================================================
1. VehicleRegistrationQuery -- Plate path (ACVR)
================================================================================
keyRef: ACVR
Required: BadgeNumber, LicensePlateNumber
Optional: LicensePlateYear, LicensePlateTypeCode, RegistrationState, VehicleIdentificationNumber, VehicleMakeCode, VehicleYear
Status: [PENDING]

Expected CommSys XML (plate only):
  <BadgeNumber>1234</BadgeNumber>
  <LicensePlateNumber>ABC1234</LicensePlateNumber>

Expected CommSys XML (plate + state):
  <BadgeNumber>1234</BadgeNumber>
  <LicensePlateNumber>ABC1234</LicensePlateNumber>
  <State>CA</State>

Notes: RegistrationState field (attributeTypeId=STATE, initialValue=AZ) -- NCIC codeTypeProvider
converts attr ID to 2-letter code. Blank default = AZ fires without state element.

7. DriverHistoryQuery -- OLN path (KQ)
================================================================================
keyRef: KQ
Required: StateDH (hidden, always AZ), OperatorLicenseNumberDH
Optional: Attention, BirthDateDH, NameFirstDH, NameLastDH, NameMiddleDH, NameSuffixDH, PurposeCode, SexCodeDH
Status: [PENDING]

Expected CommSys XML:
  <State>AZ</State>
  <OperatorLicenseNumber>D12345678</OperatorLicenseNumber>

With optional fields:
  <State>AZ</State>
  <OperatorLicenseNumber>D12345678</OperatorLicenseNumber>
  <PurposeCode>E</PurposeCode>
  <Attention>Smith J</Attention>

Notes: StateDH is a hidden text input with initialValue='AZ' (plain text, no NCIC conversion).
DH-suffix fieldIds (OperatorLicenseNumberDH etc.) isolate DH from DL field pool (LIMITATION #26).
