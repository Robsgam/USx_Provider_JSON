    permitted on the plate combo and the plate fields looked permitted on the VIN combo. It
    reported 0 OVER-PERMITTED before this fix and still reports 0 after -- the fix is invisible
    to that gate in both directions. This is exactly the shared-keyRef blindness recorded in
    knowledge-base/FIDELITY_TRIAGE.txt earlier the same day; AZ is now its second confirmed
    instance (OH_LEADS's BMVIMS DL pair is the first). Verification here is the raw-XML
    comparison plus the simulator wire, NOT a green gate.

    metadata does not define the field on that variant and a REAL blind spot when it does --
    here the mutation "removing" the field was the correct state all along, i.e. the mutant was

  THE DEFAULTS HAD TO GO IN THE SAME EDIT. ACVRV carried defaults[] for LicensePlateTypeCode='PC'
