# CONTEXT (v3.1 guardrail hardening, 2026-07-24): identifier priority is now enforced by
# existence-only EXISTS/NOT_EXISTS conditions on the CommSys combos -- NOT by set->any demotion
# alone. This corrects the v3.0 doc, which FALSELY claimed the demotion by itself made the platform
# "serialize ONLY the intended identifier." It does not: the platform unions the set[]+any[] of
# EVERY combo whose set[] is satisfied (LIMITATION #1), so a lower-priority identifier left in a
# sibling combo's any[] still bleeds into the serialized pool. v3.0 had ZERO conditions and therefore
# over-sent on every multi-identifier input (plate query also serialized VIN, DL name query also
# serialized OLN+SSN, DH name also OLN, boat reg also Hull, WMPI name also NCIC). v3.1 adds the
# proven CA_VENTURA/CA_eSUN existence-gate pattern:
#   Vehicle Plate>VIN   : ACVRV -> LicensePlateNumber NOT_EXISTS
#   DL      OLN>SSN>Name: DQSS -> OLN NOT_EXISTS; ACWL/DQN -> OLN + SSN NOT_EXISTS
#   DH      OLN>Name     : KQH -> OperatorLicenseNumberDH NOT_EXISTS
#   Boat    Hull>Reg     : ACQB/BQ -> BoatHullIdNumber NOT_EXISTS
#   WMPI    NCIC>Name    : ACQW/ACQM -> NCICNumber NOT_EXISTS
# The higher-priority identifier is ALSO dropped from every sibling combo's any[] (gate-xor-companion,
# verify_build CHECK 14), so the fired combo's serialized pool excludes it -- confirmed with
# test_commsys (e.g. plate+VIN -> ACVR fires, VIN not in pool). The badge combos (ACWL/ACQB/ACQBH)
# additionally carry dexStateUserId EXISTS so they do not shadow the no-badge fallback combos
# (DQN/BQ/BQH) whose payloads have no badge (verify_build CHECK 16); this is metadata-faithful --
# only ACWL/ACQB(H) require BadgeNumber in metadata, the DQ-Name/BQ/BQH transactions do not.
#
# The four remaining demote entries below are LEGITIMATE companions, NOT identifiers: SexCode and
# BirthDate are name-search descriptors that metadata carries in the DQ-Name / KQ-Name set[]. They
# ride along in the OLN combo's any[] (a query for an OLN may still usefully carry an entered DOB/Sex)
# without being forced into its set[]. They are not priority identifiers, so no existence gate applies.
# All confirmed against docs/reference/AZ_AZDPS_METADATA_REFERENCE.txt.
