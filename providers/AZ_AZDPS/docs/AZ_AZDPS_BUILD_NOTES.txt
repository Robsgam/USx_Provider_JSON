VALIDATOR FIXES (applied during AZ rebuild)
  1. ImageIndicator: validator now only WARNs if a QIDM maps ImageIndicator but the
     form doesn't have it. If no QIDM maps it (scope difference), no warning.
  2. Attention: validator now only WARNs if the QIDM has CommsysGetLastNameFirstName
     handler (auto-fill style). If no handler (user-typed style like AZ), no warning.
  3. RMS SSN: validator now skips SocialSecurityNumber dead-HIDLE check if the
     provider's Person form actually has an SSN field. AZ uses SSN (DQSS combo).
  All fixes verified: AZ 0 WARN, NJ 0 WARN, NY 0 WARN (all 6 JSONs clean).

INSIGHTS FOR OTHER BUILDS
  1. Validator AP #3 Race false positive: fixed in validator (added codeTypeProvider check).
     Applies to any future provider using attributeTypeId=RACE + codeTypeProvider=NIBRS.
  2. LicensePlateNumber: all providers should use the correct fieldId for RMS plate compatibility.
     NJ uses camelCase (licensePlateNumber); all other providers use PascalCase (LicensePlateNumber).
  3. ImageIndicator is NOT universal: per-provider metadata determines support.
     AZ has RelatedHitSearchIndicator instead on Gun/Article/Boat.
  4. RMS SSN handling: if provider DL form has SSN, keep SSN in RMS Person QIDM.

STATE (NCIC confirmed for AZ):
  Form: FormSelect fieldId='RegistrationState', attributeTypeId='STATE', initialValue='AZ'
  QIDM: sourceField=@('RegistrationState'), targetField='State', codeTypeProvider='NCIC'
  DH hidden state: InpH fieldId='StateDH', initialValue='AZ' (mandatory in KQ/KQH set[])

SEX (NIBRS confirmed):
  Form: FormSelect fieldId='SexCode', attributeTypeId='SEX', codeTypeProvider='NIBRS'
  RMS: useAttributeId=True passes attribute ID directly
  DH: SexCodeDH (DH-suffix isolation)

RACE (NIBRS confirmed -- AP #3 fix):
  Form: FormSelect fieldId='RaceCode', attributeTypeId='RACE', codeTypeProvider='NIBRS'
  QIDM: codeTypeProvider='NIBRS' triggers reverse-lookup
  Validator AP #3 updated to skip when codeTypeProvider present (same logic as Sex)

BIRTHDATE (AZ uses yyyyMMdd):
  CommsysParseDateRuleHandler arguments = @('yyyy-MM-dd','yyyyMMdd')

NAME FORMAT:
  FormatStringRuleHandler arguments = @(', ',' ',' ')
  Produces: "Last, First Middle Suffix"
