Transport: MQ Series Client
Routing and Configuration Information: Mnemonic Routing (TOC ID) MQMD ­ Queue Manager, Reply to Q
 The ACJIS assigned ORI for a device (or for the site) should be placed in the <Authentication>/<ORI> field in the ConnectCIC header.
 The ACJIS assigned Mnemonic for a device should be placed in the <Authentication>/<Mnemonic> field in the ConnectCIC header.
 The ACJIS assigned TOC number (also known as badge number / operator identification number) for a user should be placed in the <Authentication>/<UserName> field in the ConnectCIC header.
Security Requirements: Extensive Network Security Requirements as well as background checks. ACJIS provides documentation on requirements to agencies. Vendors must obtain such from agencies.
Logon Requirements: None at state level ­ See certification info below.
Certification Requirements: Every Agency Must Certify with the state ­ Because security is such a large issue with the state, there is a very lengthy paper process that must be completed between the agency and the state before vendors can have access to state-level resources and before any testing will be allowed. The agency is a very integral part of the implementation phase of this process and their cooperation is vital to being able to complete this process. Below are some of the written policy requirements that the vendor should be aware of that the state requires:
 Documentation indicating that any computer equipment having access to ACJIS has proper security controls to prevent unauthorized access to the system from any point.
 Documentation of the operation programs and how they prevent unauthorized device access.

 The operation program must be implemented to detect and store all unauthorized attempts to penetrate any criminal justice information system, program, or file.
 Relationships between the interface and ACJIS, including a description of the data passed from one system to another and the methods used should be documented and presented to the state.
 Documentation of security access to any tables used, password procedures, and procedures for purging and adding password codes.
 Documentation that necessary programming is implemented to enable either the locking of routing indicators to a specific device or the development of a transaction log.
Agency sponsorship is required to communicate with the AZDPS. To acquire the required documentation for the vendor to understand the state transports, transactions, and other requirements, this must be requested by the agency from AZDPS and passed from AZDPS to the agency to the vendor. Furthermore, the agency must sponsor a call with the state to allow the vendor access to the AZDPS personnel for questions regarding development and security.
