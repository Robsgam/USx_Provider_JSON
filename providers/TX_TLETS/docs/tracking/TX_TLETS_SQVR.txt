  QV Plate + QV VIN -- NOT BUILT (metadata shadows, platform auto-fired) [REMOVED v4.9, re-removed v4.17]
    keyReferences: QVLicensePlateNumber, QVVehicleIdentificationNumber
    Rob's binding v4.9 ruling (commit da78b66e). QV is NOT a devdoc (InState) or (OutofState)
    combination -- it is a metadata shadow whose set[] is a strict SUBSET of a real combo
    (QV{Plate} subset of REG/RQ, QV{VIN} subset of VIN+FRT). The extra fields on those combos are
    FRT/Type/Year qualifiers of the SAME plate/VIN query, not a state discriminator, and the
    PLATFORM AUTO-FIRES the metadata QV transaction off the larger query (same class as QW; NJ
    precedent -- state auto-runs QV, response data-mined via QRDM). An explicit combo therefore
    adds no officer capability while stealing fills from the real combos.
    Re-added IN ERROR at v4.14 (bundled into the legitimate RQ{Plate}/RQ{VIN} prefill-dead
    restoration, commit 970de807) and removed again at v4.17. audit_query_trace reports QV
    [MISSING] -- that is EXPECTED and advisory; do NOT "fix" it. See ACCEPTED_DIVERGENCES,
    rule metadata-shadow-autofired.

  RQ VIN -- Nlets Vehicle Registration, devdoc (OutofState) VIN path (VIN+Make+Year) [PENDING]
    keyReference: RQVehicleIdentificationNumber
    set: VehicleIdentificationNumber
    any: RegistrationState, VehicleMakeCode, VehicleYear
    state: In/Out
    NOT CONFIRMED, NOT CONFIRMABLE (2026-07-29): unreachable. VINVehicleIdentificationNumber is
      ordered first and its only extra set[] field is FinancialResponsibilityType, which the form
      pre-fills 'E' -- so the VIN combo always matches first and this one never fires at any fill.
      The prior "CONFIRMED: T15 2026-06-17" was false: that fill included FRT=E, so it exercised
      VINVehicleIdentificationNumber. Stale logs deleted 2026-07-29. Same class + same disposition
      as RQ Plate above (dead-combo-REMOVE-SCHEDULED, removal at TX's next bump per Rob's v4.9
      subset-shadow ruling). Officer impact: NONE.

  (QV Plate + QV VIN removed v4.9, DEX-1284: both were ungated subset-shadows of the metadata
