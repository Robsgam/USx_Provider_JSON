Find your entity, then pick the row for what you want to search by. Fill every field in Required; anything in Optional narrows the search but is not needed to run it.

2.Rows are numbered per query, in the order the system tries them. If what you typed fits more than one row, the lowest-numbered row wins — so the more you fill in, the more specific the search.
RQLicensePlateNumberThe message key — the state's own name for that transaction. It is what appears in a wire log, so quote it when asking about a specific search. The same key can appear on more than one row: one transaction often covers several search paths, and that is normal, not a duplicate.

(out-of-state)		Which path the search takes. Leaving State blank searches in-state; entering a state sends it out-of-state. Where a row says (in-state or out-of-state), that one row does both — add a State only if the record is from another state.
NCIC Image (Y)A value in parentheses is already filled in on the form. Leave it alone unless you know it should be different.

Only these paths run a search. Filling extra fields that are not listed for your row does not broaden the search — it can send you to a different row, or to none at all.
