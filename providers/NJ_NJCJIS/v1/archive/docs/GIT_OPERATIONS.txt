GitHub Setup and Operations
===========================
Created: 2026-04-09
Run git/gh commands in PowerShell or Command Prompt (NOT in Claude Code terminal).

================================================================================
INITIAL SETUP -- Install GitHub CLI and Authenticate
================================================================================

STEP 1 -- Install GitHub CLI

  winget install GitHub.cli

  If winget is unavailable, download the .msi installer from:
    https://cli.github.com

  After install, close and reopen your terminal to reload PATH.

STEP 2 -- Authenticate

  gh auth login

  When prompted:
    - Account type : GitHub.com
    - Protocol     : HTTPS (simpler) or SSH (better for frequent use)
    - Auth method  : Login with a web browser (recommended)

  Browser will open for OAuth. Approve access.

STEP 3 -- Verify

  gh auth status
  -- Expected: "Logged in to github.com as <your username>"

STEP 4 (SSH only) -- Generate and add SSH key

  ssh-keygen -t ed25519 -C "your@email.com"
  cat ~/.ssh/id_ed25519.pub
  -- Add output to: GitHub.com > Settings > SSH and GPG keys > New SSH key

  ssh -T git@github.com
  -- Expected: "Hi <username>! You've successfully authenticated..."

STEP 5 (HTTPS only) -- Personal Access Token (if needed)

  GitHub.com > Settings > Developer Settings > Personal access tokens
  > Fine-grained tokens > Generate new token
  Permissions needed: Contents (read/write), Issues, Pull Requests
  gh auth login --with-token  (paste token when prompted)

STEP 6 -- Put a new project on GitHub

  cd C:\Users\RobSgambellone\.local\bin\<PROJECT>
  git init
  gh repo create <REPO_NAME> --private --source=. --push

  git clone https://github.com/LooseConnection/NJ_NJCJIS_JSON.git

  git clone https://github.com/LooseConnection/FL_FCIC_JSON.git

================================================================================
NOTES
================================================================================

  - gh auth login handles authentication for both git and gh commands once set up.
  - Fine-grained PATs are preferred over classic tokens.
  - If working across machines, repeat Steps 1-3 on each machine.
  - Build scripts include a post-commit hook that auto-pushes on every commit.
    Manual push only needed if that hook fails.
