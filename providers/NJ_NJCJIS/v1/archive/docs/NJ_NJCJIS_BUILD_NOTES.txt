================================================================================
KEY DESIGN DECISIONS
================================================================================

  Single card per entity
    All query paths on one card. QUERYINPUTDATAMAPPING combinations route by
    populated fields. Sections variant (NJ_NJCJIS_sections.json) is the alternative.

  NJ state defaults
    All RegistrationState and LicenseState dropdowns: initialValue = "NJ".

  LicensePlateYear -- no default (optional per RQ combination)

  ArticleTypeCode codeTypeSource = CA_CLETS
    NCIC_ARTICLE_TYPE lives under CA_CLETS. Using "NCIC" gives empty dropdown.

  Firearm Make/Caliber -- FormInput free-text
    No platform code list confirmed for NJ. FL_FCIC uses same approach.

  GunQuery sourceField -- GunMake/GunCaliber (not FirearmMake/FirearmCaliber)
    Confirmed from FL_FCIC. Form fieldId must match sourceField.

  SexCode attributeTypeId = "SEX"

  BirthDate -- FormDate component

  ImageIndicator -- FormSelect YES_NO_UNKNOWN/NIBRS
    Person card: initialValue=Y (opt in to image by default).
    Vehicle card: initialValue=N (opt in explicitly).
    Must be in set[] or any[] of each matched combination to be sent.
    YES_NO_UNKNOWN shows Y/N/U; U cannot be suppressed.

  RandomRequest -- FormInput, no initialValue (Vehicle only)
    Only valid value per PDF is Y (size 5-5). Blank = not sent. Operator types Y.
    FormSelect not used -- would expose N/U which are not valid values for this field.

  Mandatory (M) fields in set[], not any[]
    State is M/Mandatory per PDF for VehicleRegistrationQuery.
    In set[] for both RQ and RQN combinations.

  set[] and any[] control matching only -- not field sending (confirmed v2.1)
    All populated attributes in the config are sent when a combination fires,
    regardless of set/any membership. See LIMITATIONS.txt item 1.

  QUERYRESULTDATAMAPPING cloned from HI_HCJDC_Results (name/provider changed)
    Field mappings pending validation against live NJ response format.

================================================================================
PLATFORM LIMITATIONS  (summary -- see NJ_NJCJIS_LIMITATIONS.txt for detail)
================================================================================

  1.  Combination routing controls matching only -- all populated attributes sent
  2.  Cleared/blank FormSelect not serialized -- use initialValue for defaults
  3.  No conditional field visibility -- workaround: single card + combination routing
  4.  No field styling -- workaround: field ordering and card titles
  5.  No standalone text/label component -- workaround: Card.props.title
  6.  Card title renders plain text only -- no HTML
  7.  YES_NO codeTypeCategory not recognized -- use YES_NO_UNKNOWN
  8.  Article Type: codeTypeSource must be CA_CLETS (not NCIC)
  9.  Firearm Make/Caliber: no platform code list -- use FormInput
  10. QUERYINPUTFORM in RMS bundle causes duplicate cards
  11. VehicleStolenQuery: not in NJ_NJCJIS.xml -- requires server-side registration
