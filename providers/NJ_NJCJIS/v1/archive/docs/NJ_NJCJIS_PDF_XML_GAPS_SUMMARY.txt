NJ NJCJIS -- DevDoc vs MetaData Discrepancies
===============================================
Date   : 2026-04-09
Source : NJ_NJCJIS DevDoc (Basic Queries Supported section) compared to NJ_NJCJIS MetaData

The following discrepancies were identified between the DevDoc specification
and the ConnectCIC provider MetaData.

--------------------------------------------------------------------------------
1. TRANSACTION IN DEVDOC BUT NOT REGISTERED IN METADATA
--------------------------------------------------------------------------------

  VehicleStolenQuery
    Documented in the DevDoc but not present in the provider MetaData.
    This transaction cannot be configured until it is registered in the MetaData.

    Note: The DevDoc lists LicensePlateNumber for VehicleStolenQuery with a size
    of 2. All other queries define this field as size 10. Please confirm.

--------------------------------------------------------------------------------
2. FIELDS IN DEVDOC BUT NOT DEFINED IN METADATA
--------------------------------------------------------------------------------

  GunQuery
    - GunModel        (Optional, max 11)
    - ImageIndicator  (Optional, Y/N)

  BoatQuery
    - ImageIndicator  (Optional, Y/N)

  ArticleSingleQuery
    - ImageIndicator  (Optional, Y/N)

--------------------------------------------------------------------------------
3. FIELD DEFINITIONS THAT DIFFER BETWEEN DEVDOC AND METADATA
--------------------------------------------------------------------------------

  BoatQuery -- RegistrationNumber
    DevDoc: max 20    MetaData: max 8

  BoatQuery -- State
    DevDoc: field not listed    MetaData: optional field in both combinations

  DriverLicenseQuery -- State (license number path)
    DevDoc: required    MetaData: optional

  VehicleRegistrationQuery -- ImageIndicator
    DevDoc: optional field    MetaData: not defined

  VehicleRegistrationQuery -- RandomRequest
    DevDoc: optional field    MetaData: not defined

  VehicleRegistrationQuery -- State
    DevDoc: mandatory in both combinations    MetaData: optional in both combinations
