NEW ISSUE FOUND: State sent as internal option ID (69509887513) instead of 'PA'.
  Root cause: Visible FormSelect with attributeTypeId='STATE' sends platform's
              internal dropdown option ID -- same bug pattern as hidden SelH.
              The issue is NOT limited to hidden fields. Any FormSelect using
              attributeTypeId='STATE' sends an internal ID.
  Fix       : Replace all State FormSelect (Sel) fields with FormInput (Inp),
              maxLength=2. Operator types 2-letter state code directly.
              Affects: Vehicle OOS, Person OOS, Boat Registration card.
              Fixed in v3.8.

NOTE -- T16 deviation: Operator did not clear PlateType and PlateYear between
  T15 and T16. Those fields were sent alongside Random=Y. Combination still
  fired as RQ correctly. Noted but does not affect pass/fail verdict on
  combination routing or Random field behavior.
