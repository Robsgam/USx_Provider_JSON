NJ_NJCJIS v3.6 -- Entity Test Plan
====================================
Date   : 2026-04-09
Version: v3.6 (field names updated to v3.13 -- 2026-04-09)
Scope  : All 7 entity tabs, all fields

FIELD NAME CHANGES (v3.13)
  LicensePlateNumber (generic) replaced by:
    LicensePlateNumberIn  -- NJ forms  (triggers RMS plate search)
    LicensePlateNumberOut -- OOS forms (triggers RMS plate search)
  State field architecture:
    NJ forms  -- SelH 'RegistrationState' (RMS only, not in QIDM) + InpH 'RegistrationStateNJ' (outbound XML)
    OOS forms -- Sel 'RegistrationStateOOS' codeTypeCategory='NJ_NIBRS_STATE' (dropdown, sends 2-letter code)
  keyReference changes (NJ combinations):
    RQ  → RQ_NJ   (Vehicle NJ plate)
    RQN → RQN_NJ  (Vehicle NJ VIN)
    DQN → DQN_NJ  (Person NJ OLN)
    OOS combinations retain original names: RQ, RQN, DQN, DQ, BQ, BQN, QG, QA

PASS CRITERIA (each test)
  - Correct combination fires (visible in query log)
  - All listed fields appear in the sent data
  - No error response from server
