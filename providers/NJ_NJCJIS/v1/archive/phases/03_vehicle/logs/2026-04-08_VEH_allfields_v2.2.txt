================================================================================
IMPLICATION
================================================================================

  A single QUERYINPUTDATAMAPPING config cannot achieve field isolation between
  RQ (plate path) and RQN (VIN path). Both paths share the same attribute list.
  When both plate and VIN fields are populated, both are sent regardless of which
  combination fires.

  In practice, an operator will fill EITHER the plate fields OR the VIN -- not both.
  If only one set is filled, only those fields are populated and sent:
    Plate-only fill --> LicensePlateNumber + optional plate fields + State sent; VIN blank/not sent
    VIN-only fill   --> VehicleIdentificationNumber + State sent; plate fields blank/not sent

  The "all fields" test is an edge case. Whether it returns results or an error
  depends on ConnectCIC server behavior with conflicting required fields in one request.
