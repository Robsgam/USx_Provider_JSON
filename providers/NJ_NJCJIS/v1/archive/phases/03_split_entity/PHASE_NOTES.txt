  QIDM unchanged (NJ_NJCJIS_DriverLicenseQuery with DQN + DQ combos).
  NCIC state pattern (codeTypeProvider=NCIC) handles both forms -- State field is visible
  on both NJ and OOS tabs. The key difference is NJ has initialValue='NJ', OOS has none.

  This is functionally equivalent to the v2.0 multi-card design since NCIC state handles
  OOS natively. The split is being tested to determine if the UX of separate tabs is
  preferable to a single Person tab with a state dropdown.
