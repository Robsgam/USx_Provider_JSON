ANALYSIS
================================================================================

  PASS -- OLN path (DQN) fired correctly.
    Only OLN and State sent. Name/DOB/SexCode excluded.
    Attribute-list split continues to work as intended.

  ISSUE -- ImageIndicator still not sent despite initialValue=Y (v1.9) and size=1 (v1.8).
    Root cause (revised): initialValue='Y' pre-populates the field but the platform
    also requires the field to be listed in the combination's any[] array to include
    it in the outgoing request. Fields defined as attributes but absent from set[] and
    any[] are not serialized even when populated.

    DQN combination currently:
      set = [OperatorLicenseNumber, RegistrationState]
      any = []   <-- ImageIndicator is missing here

    Fix: add ImageIndicator to any[] of the DQN combination.
    This corrects our earlier understanding of LIMITATION #10.

  FIX #1 -- Add ImageIndicator to DQN any[].
    Revised DQN: set=[OLN, State]  any=[ImageIndicator]
    ImageIndicator will then be sent when populated (Y or N selected).
    Blank/cleared field will still not be sent -- this is acceptable behavior
    for an optional field.

  FIX #2 -- Remove M.I. and Suffix from Person form.
    NameMiddle and NameSuffix are not defined in the NJ_NJCJIS PDF.
    Remove NameMiddle_Input and NameSuffix_Input from ROW_3.
    ROW_3 changes from 4-column (3,3,3,3) to 2-column (6,6): BirthDate + Sex only.
    Remove NameMiddle and NameSuffix from Name attribute sourceField in
    DriverLicenseQuery_Name config. FormatStringRuleHandler drops to 1 separator.

  LIMITATION #10 REVISED:
    Prior understanding: set/any controls matching only; all populated attributes sent.
    Corrected: set[] and any[] control both matching AND sending. Attributes defined
    in the config but not listed in set or any of the matched combination are NOT sent.
    To send an optional field, it must appear in the any[] of the relevant combination.
