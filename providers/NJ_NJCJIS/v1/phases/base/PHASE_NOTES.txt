================================================================================
KEY LEARNINGS
================================================================================

  - PowerShell ConvertTo-Json unwraps single-element arrays to string and
    serializes empty @() as {}. Fix: use List<string> for nodes property.
  - ROOT node must have NO parent property (not parent=""). HIDLE/CA_ESUN pattern.
  - Form fieldId must match QUERYINPUTDATAMAPPING sourceField exactly.
    Wrong: sourceField='FirearmMake' + fieldId='FirearmMake'
    Right: sourceField='GunMake'    + fieldId='GunMake' (FL_FCIC pattern)
