NEW METADATA CHANGES (v2 vs v1):
  1. VehicleStolenQuery -- new transaction, 3 combos (QV x3 in XML -> QVN/QVP/QVV invented)
  2. RandomRequest -- new mandatory field on VehicleRegistrationQuery (Y=random, N=full per NJ A-134-97)
  3. ImageIndicator -- added to all 6 transactions (was only on DL in v1 XML)
  4. GunModel -- new optional field on GunQuery
  5. State REMOVED from BoatQuery entirely
  6. RegistrationNumber maxLength 8->20 on BoatQuery
  7. State + LicensePlateTypeCode moved from any[] to set[] on VehicleRegistrationQuery
  8. All keyRefs changed -- XML has duplicates, all need invented distinct keyRefs

INVENTED keyRef MAP (XML duplicate -> build keyRef):
  BoatQuery:               QB, QB     -> QB (Reg), QBN (Hull)
  DriverLicenseQuery:      FULL, FULL -> DQ (Name), DQN (OLN)
  VehicleRegistrationQuery: RAND x2, FULL x2 -> RQ (Plate), RQN (VIN)
  VehicleStolenQuery:      QV x3     -> QVN (NCIC#), QVP (Plate), QVV (VIN)
  ArticleSingleQuery:      QA        -> QA (unchanged)
  GunQuery:                QG        -> QG (unchanged)

PDF vs XML DISCREPANCIES (metadata wins):
  BoatQuery: PDF shows cross-optional IDs in combos; XML does not
  DriverLicenseQuery: PDF shows 3 combos (in/out split); XML has 2
  VehicleRegistrationQuery: PDF shows State optional for plate; XML has State in set[]
