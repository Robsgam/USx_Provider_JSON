GROUND RULES (apply to every test)
--------------------------------------------------------------------------------
1. FULL PAGE RELOAD between every test. The clear-form button remembers the
   last active query (platform bug, reported to Cringer 2026-05-12).
2. Server-log REQUEST + RESPONSE XML capture is MANDATORY for every test that
   fires a query. XML comes from server logs, NOT the browser F12 Network tab.
   post_test.ps1 -XmlRequest blocks PASS without it. "Not captured" = UNTESTED.
3. Before each test, create a stub:
     tools/new_test_log.ps1 -Provider NJ_NJCJIS -Variant MC -Version 3.7-SEPARATE
       -Entity Vehicle -Combo <TestID> -Description "<short description>"
   (Version string distinguishes branch logs from mainline v3.5 logs.)
4. After each test, save instantly:
     tools/post_test.ps1 -Provider NJ_NJCJIS -Entity Vehicle -Query <q>
       -Combo <TestID> -Result PASS|FAIL -Description "..." -XmlRequest "..."
5. Field types (do not improvise): Plate Number / VIN / NCIC Number / Plate Year
   are TEXT inputs. Vehicle Make / Plate Type / State / Random / Image are
   DROPDOWNS (select, do not type free text).
6. Mainline v3.5 test package state is NOT reset -- branch logs are additive.

Q1  Reg plate -> RQ alone, NO QV                                        [    ]
    Steps : Plate ABC1234 on PLATE SEARCH card. Submit.

    PASS  : RQ only + all defaults + zero QV.

    Steps : VIN 1HGCM82633A123456 on VIN SEARCH card. Submit.
    Expect: RQN fires: VIN + RandomRequest=N + ImageIndicator=N + State=NJ.
            No QV. RMS fires (vehicle.vinNumber).

    Expect: RQ_RAND combo fires (conditions RandomRequest EQUALS Y);
            XML carries RandomRequest=Y. Still no QV.
    PASS  : RandomRequest=Y in request XML.

Q4  RANDOM plate -> QVP alone (XML parity with mainline)                [    ]
    Steps : Plate ABC1234 in RANDOM card plate. Submit.
    Expect: ONE transaction: MessageType VehicleStolenQuery, MessageKey QV.
