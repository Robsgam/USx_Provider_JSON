Secondary: Authentication/Mnemonic

 The SCIC assigned ORI for a device (or for the site) should be placed in the
    <Authentication>/<ORI> field in the ConnectCIC header.
    *** <Authentication>/< OriginatingAgencyORI> can be used to override the
    <Authentication>/<ORI> to send on-behalf-of another ORI

 The SCIC assigned Mnemonic for a device should be placed in the
    <Authentication>/<Mnemonic> field in the ConnectCIC header.

Certification Requirements:
Need Site Sponsor
It is recommended that communication with the state be through a state-recognized agency,
such as the agency that will be using the software solution.

State-Level Certification
Commsys has completed NJSP headquarters certification of our product. This allows the
vendor to bypass the first stage of testing and commence testing from the site focusing on
the second phase of the state's certification process, which involves testing at the site
against the state's test system. Once the state has seen all of the queries tested and is
satisfied with the data, they will then allow the site to connect to the live system. Once this
certification is completed at the vendor's first site in New Jersey, the state usually allows
the vendor to install at other sites without additional certification. However, for each site,
the State must still be notified so site can be configured properly for access.
