# emit_test_plan DOES print the reason by name ("'OriginatingAgencyCaseNumber' has no test value

# That reason was TRUE of the incomplete fill and FALSE of the combination: QWA.OCA is ordered
# BEFORE QWA.N and is strictly more specific, so a complete fill reaches it.
