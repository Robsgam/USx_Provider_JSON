NJ_NJCJIS -- New Jersey
================================================================================
Status: v2.0 BASE+MC | 64P/0F/3W/2LIM | Live tested 2026-04-29

NJ-1: VehicleStolenQuery registered separately
  NJ CommSys has VehicleStolenQuery as a distinct transaction. Vehicle QIDM covers
  VehicleRegistrationQuery; a second QIDM covers VehicleStolenQuery. Both target
  the same Vehicle entity but different query values, so LIMITATION #2 does not apply.
  RandomRequest (Y/N): RAND combo = stolen-only (Y), FULL combo = all-data (N).
  See reference_nj_randomrequest_analysis.md for combo details.

NJ-2: State initialValue='NJ' is safe
  NJ has no separate in-state vs OOS keyRefs. State is always in set[] for primary
  combos. initialValue='NJ' does not change which combo fires (unlike NY -- see
  PLATFORM_LIMITATIONS.txt #30). Safe to default.

NJ-3: BirthDate format MMddyyyy
  CommSys expects: CommsysParseDateRuleHandler arguments=['yyyy-MM-dd','MMddyyyy']

NJ-4: AUTH keyReference and RMS autoSelect lost in rebuild
  Manual fixes (AUTH keyReference, RMS Person+Vehicle autoSelect=true) applied
  2026-04-30 were overwritten by build script. Build script must include these.
  Cross-provider consistency: NY/AZ/FL have autoSelect=true on RMS QIDMs.

NJ-5: Confirmed attribute IDs (from live test)
  NJ state: 69509884952, PA state: 69509887513, NY state: 69509888105
  Male sex: 69509891711, Female sex: 69509894381, Unknown sex: 69509886562

FL_FCIC -- Florida
================================================================================
Status: v3.0 BASE+MC | 100P/0F/1W/4LIM | Import PENDING

FL-1: Entity-split BLOCKED (LIMITATION #28)
  FL originally used Person-FL + Person-OOS split. codeTypeProvider reverse-lookup
  breaks with multiple Person QIFs. Redesigned to single 6-card Person QIF (v2.2+).
  Do NOT attempt entity-split on FL.

FL-2: FL-specific transaction keys
  FL uses FCIC keys: FRQ (vehicle reg), FDQ (driver license), QW (firearm),
  KQ (driver history), FBQ (boat stolen). Mixed with NCIC/Nlets keys in same
  transactions.

FL-3: DriverHistoryQuery (KQ) is FL-specific
  KQ includes PurposeCode (FormInput, maxLength=1, initialValue='C').
  Not all providers have DH -- check metadata.

FL-4: Boat combo priority conflict
  QB+Hull and QB+Reg combos unreachable due to FBQ combos firing first.
  FBQ+Hull fires before QB+Hull because FBQ QIDM evaluates first (autoSelect=true
  vs QB autoSelect=false). Three QB combos remain functional (QB+CG, QB+NCIC, QB+PCN).
  Resolution requires separate BoatStolenQuery transaction type (platform change).

FL-5: BoatHullIdNumber maxLength=62
  Longer than NJ standard (20). Provider-specific metadata value.

FL-6: VehicleRegistrationQuery has no State requirement
  FL vehicle reg is in-state only. State not in metadata for this query.
  Do NOT add State to vehicle combos unless metadata includes it.

FL-7: DL+DH shared form (6-card design)
  Uses LIMITATION #24/#25 pattern: autoSelect + queriesToDeselect + DH-suffix fieldIds.
  Reference implementation for shared-form DL+DH.

FL-8: BoatQuery QB+Hull/QB+Reg routing via RelatedHitSearchIndicator
  QB+Hull and QB+Reg were unreachable because FBQ+Hull/FBQ+Reg shared the
  same set[] field and fired first. Fixed 2026-05-05: RelatedHitSearchIndicator
  (metadata field, Y/N, exclusive to QB combos) promoted from any[] to set[]
  on QB+Hull and QB+Reg. Officer types Y in "Stolen Search" to route to NCIC
  stolen; blank = FL registration (FBQ). QB combos ordered before FBQ.
  Fallback tag: FL_FCIC_PRE_QB_ROUTING (revert if server rejects field).
  All 12 boat combos now reachable.

NY_NYSPIN_EJUSTICE -- New York
================================================================================
Status: v1.1 BASE+MC | 71P/0F/0W/5LIM | Import PENDING

NY-1: WINQ/MINQ transactions have no XML in metadata
  Wanted Inquiry (WINQ) and Missing Person Inquiry (MINQ) appear in metadata
  but have no Transaction XML defined. Cannot build QIDMs until metadata updated.
  Flagged for CommSys gap summary.

NY-2: State initialValue must NOT be set (LIMITATION #30)
  NY has separate in-state (RCAR) vs OOS (RVIN) combos. Setting initialValue='NY'
  causes OOS combos to fire for in-state queries. Blank default preserves
  documented query types. Card title hints guide officers.

NY-3: DL Name path uses separate transaction
  NyNyspinDriverLicenseNameQuery (DGRP) is a distinct transaction in metadata.
  Allows DL Name path QIDM without hitting LIMITATION #2.
  NOTE: DGRP was later removed; DLICN restored as single DL QIDM with checkbox.
  See project_ny_nyspin_dlicn_removal.md for revert instructions.

NY-4: DriverHistoryQuery Name path blocked
  Both DH combos use keyRef=DALL. No separate transaction exists.
  Invented DALH keyRef resolves duplicate keyRef issue.
  DH co-fires with DL on OLN entry = correct workflow.

NY-5: BirthDate format MMddyyyy
  Same as NJ. Arguments=['yyyy-MM-dd','MMddyyyy']

NY-6: RaceCode NIBRS_RACE/NIBRS confirmed
  codeTypeSource=NCIC gave empty dropdown. Fixed to NIBRS source (v1.12).

NY-7: BoatQuery and DriverHistoryQuery are ACTIVE
  Both transactions exist in metadata with full XML definitions.
  BoatQuery: 4 combos (RVEH/RCAR in-state, BVEH/BVIN OOS). Confirmed live.
  DriverHistoryQuery: 2 combos (DALL OLN, DALH Name). Co-fires with DL. Confirmed live.

================================================================================
CROSS-PROVIDER CONSISTENCY RULES
================================================================================

These patterns MUST match across all providers. Differences require metadata
justification documented in the provider's section above.

1. RMS autoSelect=true on all RMS QIDMs
   Confirmed: NY, AZ, FL. Missing: NJ, HI, LA (build script fix needed).

2. AUTH keyReference present
   Missing from NJ, HI, LA build scripts. Must be added.

3. ImageIndicator in combo any[] or set[]
   Must be in at least one combo per entity where it appears on the form.
   Missing: HI Vehicle (HI-2).

4. queryLabel standard values
   Vehicle Registration, Driver License, Driver History, Firearm, Article, Boat, RMS.
   All providers must use these exact labels.

5. PlateType default=PC, PlateYear default=current year
   Confirmed NJ, applied NY. Safe across all providers (no combo routing impact).

6. YES_NO_UNKNOWN/NCIC for all Y/N dropdowns
   No provider should use YES_NO, YESNO, or other variants.
