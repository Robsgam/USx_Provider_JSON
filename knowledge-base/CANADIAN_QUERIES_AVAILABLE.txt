SECTION 3 — CANADIAN DL (UQ) — FIELD DEFINITIONS
================================================================================

All Canadian queries share two NLETS-standard routing fields:
  ReasonCode                      M   maxLen=1   Reason for query
  PersonPropertyInSightIndicator  M   maxLen=1   Person/Property in sight (Y/N)

Canadian DL core fields (NLETS/CPIC standard — same across all providers):

  Field                           M/O  maxLen  Notes
  ------------------------------  ---  ------  -----
  Name                            M    30-80   Last,First composite
  BirthDate                       M    8-10    DOB (format varies by provider)
  SexCode                         M    1       M/F/U
  ReasonCode                      M    1       RSN — reason for query
  PersonPropertyInSightIndicator  M    1       PPS — Y or N
  OperatorLicenseNumber           O    20      Optional for UQ; REQUIRED for WQ
  State / NletsDestination        M    2       Province destination code

Provider-specific wrapper fields (NOT part of NLETS standard):
  CaRequestPurposeCode            CA_CLETS only    CA-mandated purpose code
  Requestor                       FL_FCIC only     Requesting user (maxLen=30)
  NletsDestination                CA_CLETS only    Explicit destination field
  FormORI                         OR_LEDS only     Form ORI (maxLen=9)
  ImageIndicator                  NY_NYSPIN only   Image flag
  MiscellaneousDescriptiveText    NY_NYSPIN only   Free text (maxLen=200)

UQ Combination (standard):
  set[]: Name, BirthDate, SexCode, ReasonCode, PPS, Province/Destination
  any[]: OperatorLicenseNumber

WQ Combination (OLN-only, non-live provinces):
  set[]: OperatorLicenseNumber, ReasonCode, PPS, Province/Destination
  any[]: (none)
